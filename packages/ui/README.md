# @dynamic-dome/ui

React components for DoMe Dynamics.

## Import

```tsx
import "@dynamic-dome/ui/styles.css";
import { Button, Card, DoMeHero, MiniAppShell, StatusPill } from "@dynamic-dome/ui";
```

## Components

- Brand: `Logo`, `DoMeHero`
- Layout: `Section`, `Eyebrow`, `SectionHeading`, `AppShell`
- Primitives: `Button`, `Badge`, `Card`, `Input`, `Textarea`, `StatusPill`, `CommandCard`
- Miniapp-inspired React components: `MiniAppShell`, `BottomTabs`, `StatChip`, `QuickActionGrid`, `ActivityList`
